{{/* Image gallery: justified rows done in CSS (no JS). Each thumbnail links to the original image and opens in the page lightbox (assets/js/main.js). Params: match glob of page resources, e.g. "redesign-1/mobile/*" (required) alt optional prefix for the alt text, e.g. "Low-fidelity mockup" Alt text is built from the file name: "01-list-view-mobile.png" becomes "List view mobile" (or "Low-fidelity mockup: List view mobile"). */}} {{ $prefix := .Get "alt" }} {{ $images := .Page.Resources.Match (.Get "match") }}
